Organizador de Dados para Declaração do Imposto de Renda

📌 Sobre o projeto

Este projeto foi desenvolvido como parte de um desafio prático, com o objetivo de criar uma ferramenta no Excel para facilitar a organização de informações necessárias à declaração do Imposto de Renda.

A planilha reúne dados do titular, informes de rendimentos bancários e registros de entradas financeiras, ajudando a centralizar as informações em um único lugar.

⚙️ Funcionalidades

Dados do titular: organização das informações cadastrais.

Informes bancários: registro dos bancos, valores e documentos de referência.

Controle de entradas: registro de datas, categorias e valores recebidos.

Cálculos automáticos: utilização de fórmulas para somar valores e agrupar entradas por categoria.

Organização dos dados: separação das informações em abas para facilitar o preenchimento e a consulta.

🛠️ Ferramentas utilizadas

Microsoft Excel

Fórmulas e funções do Excel

Validação e organização de dados

🎯 Objetivo

Desenvolver uma ferramenta prática e organizada que facilite o controle das informações financeiras, tornando a preparação dos dados para a declaração do Imposto de Renda mais simples e eficiente.

📚 Aprendizados

Com este projeto, pude praticar a organização de dados em planilhas, o uso de fórmulas e a criação de uma ferramenta voltada à resolução de uma necessidade real.

Observação: Esta ferramenta auxilia na organização das informações, mas não substitui a declaração oficial nem a orientação de um profissional contábil quando necessária.
